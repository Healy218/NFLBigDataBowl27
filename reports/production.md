# Position production (player_play, REG)

Generated by `uv run python -m eeg.outcomes.production`. Per player-season measures from `player_play.csv`
(competition data only); the table is `data/processed/production_seasons.parquet` (not committed). Aggregates only.
Each measure is a ratio of season sums (num / den). Checks use qualified player-seasons (≥ 100
plays and ≥ 6 games with a play): 489 of 722, 293 prospects.

Measures (`better`: direction of good):
- `plays_per_game`: plays per game (WR, TE, OL, DL, DB)
- `target_rate`: targets per route (WR, TE)
- `yprr`: receiving yards per route run (WR, TE)
- `separation`: separation at the throw (yd) (WR, TE)
- `yac_oe`: YAC over expected (WR, TE)
- `pressure_allowed_rate`: pressures allowed per pass block (OL)
- `peak_pressure_prob`: peak pressure probability allowed (OL)
- `sack_allowed_rate`: sacks allowed per pass block (OL)
- `pressure_rate`: pressures per pass rush (DL)
- `sack_rate`: sacks per pass rush (DL)
- `get_off`: get-off time (s) (DL)
- `tackle_rate`: tackle involvements per snap (DL, DB)
- `tfl_rate`: tackles for loss per snap (DL, DB)

Columns: `seasons` / `prospects` with a value; `opp_median`: median opportunities per season (routes, pass blocks,
rushes, snaps, or plays); `rel`: split-half reliability within the group (alternate games, Spearman–Brown);
`retest`: r between consecutive seasons (`pairs`); `r_plays_per_game`: within-group r with plays per game (does
the team play him more?); `rho_pick`: Spearman ρ with overall pick in the first qualified season (drafted;
negative = earlier picks score higher).

## Decision (open decision 1, `outcomes` in config/physics.yaml)

- Primary outcome, every group: `playing_time` (all prospects, zeros kept; within group only).
- Secondary production outcome: WR `yprr`, TE `yprr`, DL `pressure_rate`, OL `peak_pressure_prob`. DB: none credible.
- In-game explosion used with η, not as an outcome: `get_off`.
- Binary rates of rare events (sacks, sacks allowed, tackles for loss) are too noisy per season (rel 0.2–0.4);
  continuous or more frequent versions win (peak pressure probability over pressure allowed).
