# Field channels

Generated by `uv run python -m eeg.ngs.channels`. Clean tracks only (glitch tracks dropped), REG + POST.
Peaks hold for 3 frames. Burst: first 1.5 s after the snap, plays starting below
1.0 m/s. Per-play, per-game and per-season tables are in `data/processed/field_*.parquet`
and the lab side in `data/processed/lab_channels.parquet` (not committed). Aggregates only.

- Plays: 263,695 (92% burst-eligible); player-games: 8,279;
  player-seasons: 723 (510 with ≥ 100 plays, 302 prospects).
- Units: speed m/s, ke J/kg, acceleration m/s², power W/kg.
